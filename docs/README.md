# Документация проекта

Документацию делим на две части.

## `official/` — официальные документы

То, что сдаём преподавателю: техническое задание и отчётные документы по
лабораторным. Формат — PDF (так требует ТЗ, раздел 7). Сданный документ
задним числом не правим: если что-то поменялось, это фиксируется в
следующей версии документа или в отчёте следующей лабораторной.

| Файл | Что это |
| --- | --- |
| `lab01-tech-spec.pdf` | Техническое задание (лаб. №1) |

## `working/` — рабочие документы

Наш внутренний план, заметки, черновики схемы БД и API. Формат — Markdown,
правим постоянно, по мере работы над проектом.

| Файл | Что это |
| --- | --- |
| `plan.md` | Рабочий план: архитектура, черновая схема БД, открытые вопросы |

## Документация к коду

Описание REST API, схема БД и инструкция по развёртыванию ведутся в
Markdown прямо в репозитории (ТЗ, раздел 7). Инструкция по развёртыванию —
корневой `README.md`.
